# DecodeLab Tasks
A collection of frontend development projects completed as part of **DecodeLab tasks**, 
showcasing my ability to build responsive, interactive, and visually appealing web interfaces using HTML, 
CSS, and JavaScript.

The repository contains multiple mini-projects, each focused on different frontend development concepts including website layout, 
responsive design, user interaction, DOM manipulation, and basic application logic.

# Projects
1. CrustyBakes — Bakery Website
A modern bakery landing page designed for a bakery business.

**Features:
* Hero section
* Bakery product showcase
* About section
* Why Choose Us section
* Customer testimonials
* Contact information
* Responsive layout
* Hover effects and interactive styling

**Technologies:**
* HTML5
* CSS3

2. Chop Chop — Restaurant Website
A responsive restaurant website designed to showcase meals, restaurant information, customer reviews, and contact options.

**Features:**
* Responsive navigation bar
* Hero section
* About section
* Popular dishes/menu
* Food pricing
* Why Choose Us section
* Customer reviews
* Contact form
* Mobile navigation menu
* Smooth scrolling
* Responsive design

**Technologies:**
* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts

JavaScript is used to control the mobile navigation menu and automatically close the menu when a navigation link is selected.

3. To-Do List App
A simple interactive task management application that allows users to create and manage their daily tasks.

**Features:**
* Add new tasks
* Mark tasks as completed
* Delete individual tasks
* Clear all tasks
* Automatically track remaining tasks
* Add tasks using the Enter key
* Scrollable task list
* Responsive design

**Technologies:**
* HTML5
* CSS3
* JavaScript

The application uses JavaScript DOM manipulation and event listeners to dynamically create, update, and remove tasks.

# Getting Started
Each project is a standalone frontend application and can be run directly in a web browser.

# Clone the repository
```bash
git clone YOUR_REPOSITORY_URL
```
# Navigate into the repository
```bash
cd DecodeLab-Tasks
```
Open any project's `index.html` file in your browser.

For the best development experience, you can use **VS Code with the Live Server extension**.
